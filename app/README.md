# تطبيق المحاسبة للأندرويد

تطبيق محاسبي بسيط لإدارة الإيرادات والمصروفات باللغة العربية.

## المميزات
- إضافة وتسجيل المعاملات المالية
- تصنيف المعاملات (إيرادات/مصروفات)
- عرض التقارير والإحصائيات
- واجهة باللغة العربية
- حفظ البيانات محلياً

## التقنيات المستخدمة
- Kotlin
- Room Database
- MVVM Architecture
- Material Design
- Coroutines
- LiveData

## التثبيت
1. انسخ المستودع
2. افتح المشروع في Android Studio
3. شغل التطبيق
